### 基本情報

| 項目        | 値                                                                                                                   |
|-------------|----------------------------------------------------------------------------------------------------------------------|
| **ファイル名**  | `penguin-marker.patt`                                                                                                |
| **ファイルパス**  | `/src/assets/markers/penguin-marker.patt`                                                                            |
| **生成日**  | 2025-10-01（Phase 1）                                                                                                  |
| **生成ツール** | [AR.js Marker Training](https://ar-js-org.github.io/AR.js/three.js/examples/marker-training/examples/generator.html) |
| **元画像**  | `assets/penguin-logo.png`                                                                                            |

### 生成時パラメータ

| パラメータ            | 値             | 説明                               |
|------------------|----------------|------------------------------------|
| **patternRatio** | **0.80**       | 🚨 **最重要**: 実行時設定と一致必須 |
| **画像サイズ**      | 512x512px      | マーカー生成時の推奨サイズ                 |
| **マーカータイプ**      | Pattern Marker | カスタムパターンマーカー                       |
| **黒枠**         | 薄い（20%）       | patternRatio=0.80により               |
| **内部パターン**     | 大きい（80%）      | ペンギンロゴが占める割合                    |

### 実行時の必須設定

#### ⚠️ 重要：patternRatioの一致

```html
<a-scene
  arjs="patternRatio: 0.80; ..."
>
```

**絶対に変更してはいけません！**

マーカー生成時の`patternRatio`と実行時の設定が一致しないと：
- ❌ マーカー検出距離が極端に短くなる
- ❌ 検出精度が大幅に低下
- ❌ ユーザー体験が著しく悪化

#### 正しい設定例

```html
<!-- ✅ 正しい設定 -->
<a-scene
  embedded
  arjs="sourceType: webcam; patternRatio: 0.80; trackingMethod: best; debugUIEnabled: false;"
  vr-mode-ui="enabled: false"
>
  <a-marker type="pattern" url="./assets/markers/penguin-marker.patt" id="marker">
    <!-- ... -->
  </a-marker>
</a-scene>
```

#### 誤った設定例

```html
<!-- ❌ 絶対にやってはいけない -->
<a-scene
  arjs="patternRatio: 0.5; ..."  <!-- デフォルト値に変更してはダメ -->
>
```

## 📊 マーカー設計の推奨事項

### 検出精度を高めるデザイン

#### ✅ 推奨
- **高コントラスト**: 白背景に黒ペンギン
- **非対称デザイン**: 回転してもユニークに識別可能
- **シンプルなパターン**: 複雑すぎない形状
- **十分なサイズ**: 印刷時5cm以上

#### ❌ 避けるべき
- 低コントラスト（グレー系）
- 対称的すぎるデザイン
- 細かすぎる線や文字
- 小さすぎるマーカー（3cm未満）

### 印刷時の注意

| 項目         | 推奨    | 備考               |
|--------------|--------|-------------------|
| **用紙**     | マット紙   | 光沢紙は反射で誤検出 |
| **サイズ**      | 5cm以上 | 最適距離30-50cm    |
| **印刷品質** | 高品質  | 300dpi以上         |
| **カラー**      | カラー推奨 | モノクロでも可           |

## 🔧 patternRatioの選択ガイド

### いつ0.80を使うか？

- ✅ カスタムロゴをマーカーにする場合
- ✅ ロゴ部分を大きく見せたい場合
- ✅ 黒枠を目立たせたくない場合

### いつ0.5（デフォルト）を使うか？

- ✅ AR.jsの標準マーカーを使う場合
- ✅ Hiroマーカーなど既存マーカー
- ✅ 黒枠をしっかり作りたい場合

### patternRatio早見表

| 値      | 黒枠の幅       | 内部パターン           | 用途      |
|---------|---------------|-------------------|-----------|
| 0.3     | 非常に太い（70%） | 非常に小さい（30%）     | 特殊用途  |
| **0.5** | **太い（50%）**  | **標準（50%）**      | **デフォルト** |
| 0.7     | 中程度（30%）   | 大きい（70%）          | カスタムロゴ    |
| **0.8** | **薄い（20%）**  | **非常に大きい（80%）** | **ペンギン**  |
| 0.9     | ほぼなし（10%）     | 全体（90%）          | 画像そのまま  |

## 🚨 トラブルシューティング

### 検出距離が短い場合

1. **patternRatioを確認**
   ```html
   <!-- 必ず0.80になっているか確認 -->
   <a-scene arjs="patternRatio: 0.80; ...">
   ```

2. **マーカーサイズを確認**
   - 印刷サイズ5cm以上か？
   - マーカーがぼやけていないか？

3. **照明を確認**
   - 明るさは十分か？
   - 影がマーカーにかかっていないか？

### 検出が不安定な場合

1. **平滑化設定を確認**
   ```html
   <a-marker smooth="true" smoothCount="10" ...>
   ```

2. **カメラの設定を確認**
   - 解像度は適切か？
   - フォーカスが合っているか？
