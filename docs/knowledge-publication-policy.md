# AIアンバサダー公開知識ポリシー

この文書は、AIアンバサダーへ提供する構造化知識の公開範囲を定める一次ポリシーです。

- リポジトリ内の出典で確認できる公開情報だけを登録する。
- 出典で確認できない事実や現在の状態を推測しない。
- 機密数値、顧客名・顧客情報、未確定の価格・見積もり、内部役割・社内情報を登録しない。
- 未登録の価格、採用、実績、問い合わせ先は、登録されていないことだけを案内する。
- 挨拶や会社紹介だけではCalendarを参照せず、明確な予定・公開イベント・空き時間の質問だけをCalendar経路へ送る。
- Calendarではタイトルが`[公開]`で始まる予定だけ、公開タイトル、開始・終了時刻、`[公開説明]`以降の説明を回答する。
- 非公開予定はタイトルや内容を回答せず、空き時間判定でbusyとしてだけ扱う。
- Calendarの参加者、場所、Meet URL、内部説明、作成者情報は回答しない。
- Calendarはサーバー側で固定設定し、利用者向けGoogle OAuth UIや認証情報入力を表示しない。
- 各項目に出典、出典の更新日、知識として確認した日を保持する。

公開範囲を拡張する場合は、一次資料と公開承認を追加してから構造化知識を更新します。
