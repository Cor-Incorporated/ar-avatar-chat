# デバッグモード実装

**作成日**: 2025-10-05  
**作成者**: 寺田康佑（PdM）  
**目的**: 本番環境でのログ削減とデバッグ性の両立

---

## 📋 実装の背景

### 問題
- モバイルでConsole.logを見るのは困難（Remote Debuggingが必要）
- 大量のデバッグログが本番環境では不要
- しかし、問題発生時にはログが必要
- ユーザーに見せるべき情報とデバッグ情報が混在

### 解決策
**URLパラメータによるデバッグモード切り替え**を実装しました。

---

## 🚀 実装内容

### 1. デバッグモードフラグ

```javascript
// URLパラメータ ?debug=true で有効化
const urlParams = new URLSearchParams(window.location.search);
const DEBUG_MODE = urlParams.get('debug') === 'true';
```

#### 使用方法

| URL                                   | モード      | ログ出力   | Stats表示 |
|---------------------------------------|----------|--------|---------|
| `https://your-domain.com/`            | **本番** | ❌ 最小限 | ❌ 非表示  |
| `https://your-domain.com/?debug=true` | **デバッグ** | ✅ 詳細   | ✅ 表示    |

### 2. ログ関数の定義

```javascript
// デバッグログ（debug=trueの時のみ出力）
const debugLog = (...args) => {
  if (DEBUG_MODE) console.log(...args);
};

// デバッグ警告（debug=trueの時のみ出力）
const debugWarn = (...args) => {
  if (DEBUG_MODE) console.warn(...args);
};

// エラーログ（常に出力）
const errorLog = (...args) => console.error(...args);
```

### 3. ログの分類

#### デバッグログ（debug=true時のみ）
- `[Mobile]` モバイル検出情報
- `[Camera]` カメラ解像度・フレームレート
- `[Marker]` マーカー検出の詳細（角度、距離、スケール）
- `[Orientation]` 画面向き変更
- `[Init]` 初期化情報

#### エラーログ（常に出力）
- `[Camera]` カメラアクセス失敗
- VRMロードエラー
- 重大なエラー

#### UI表示（ユーザー向け）
- ステータス表示（#status）
- 警告ダイアログ
- エラーメッセージ

   - マーカー検出情報を確認

## 📱 モバイルでのデバッグ方法

### Chrome Remote Debugging

#### 準備（Android）
1. AndroidデバイスでUSBデバッグを有効化
2. PCとUSBケーブルで接続
3. PC Chromeで`chrome://inspect`を開く
4. デバイスのブラウザが表示される

#### 準備（iOS）
1. iPhoneでWebインスペクタを有効化
   - 設定 → Safari → 詳細 → Webインスペクタ
2. MacとUSBケーブルで接続
3. Safariの「開発」メニューからデバイスを選択

#### デバッグ手順
1. モバイルで`https://ar-avatar-chat.vercel.app/?debug=true`を開く
2. PC側でinspectを開く
3. Consoleタブで詳細ログを確認

1. **初回アクセス**
   - `?debug=true`でアクセス
   - カメラ解像度を確認
   - 基本動作を確認

2. **問題発生時**
   - `?debug=true`で詳細ログを確認
   - マーカー検出の角度・距離を測定
   - FPSとパフォーマンスを監視

3. **本番リリース前**
   - デバッグモードなしでテスト
   - ログがクリーンであることを確認
   - エラーハンドリングを確認

### トラブルシューティング

#### デバッグモードが有効にならない
- URLパラメータが正しいか確認
- `?debug=true`（小文字）
- `&debug=true`ではない（最初のパラメータ）

#### Statsが表示されない
- デバッグモードが有効か確認
- A-Frameのバージョンを確認（1.7.0+）
- ブラウザの互換性を確認
