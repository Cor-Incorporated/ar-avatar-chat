**作成日**: 2025-10-05  
**作成者**: 寺田康佑（PdM）  
**優先度**: 🚨 **緊急最高**

---

## 📋 深刻な問題

### 症状
- PCでは大幅に改善（30-40cm検出可能）
- **モバイル縦向きでは10cm以内でないと検出不可**
- 斜め角度にするとすぐにマーカーロスト
- **実用不可能なレベル**

### 影響
- B2Bデモで使用不可
- 名刺ARの根本的な価値提供が不可能
- プロジェクトの成功が危機的状況

---

## 🔍 根本原因の分析

### なぜPCで改善されたのにモバイルで改善されないのか？

#### 原因1: **解像度の未指定**
```html
<!-- 現在の設定（問題） -->
<a-scene arjs="sourceType: webcam; ..." >
```

- 解像度を指定していない
- **PCはデフォルトで高解像度（1280x720以上）を使用**
- **モバイルはデフォルトで低解像度（640x480以下）を使用**
- モバイルの低解像度では、遠距離のマーカー検出が困難

#### 原因2: **モバイルカメラの制約**
- モバイルのカメラは省電力のため低解像度モードがデフォルト
- ブラウザがパフォーマンスを優先して解像度を下げる
- 縦向きでは画面比率の関係で、さらに解像度が制限される

#### 原因3: **信頼度閾値の設定ミス**
```html
<!-- 従来の設定 -->
<a-marker minConfidence="0.6" ...>
```

- `0.6`は中程度の閾値
- モバイルの低解像度では、この閾値が高すぎる
- 近距離でないと信頼度スコアが`0.6`を超えない

#### 原因4: **Smoothing設定が過剰**
```html
<!-- 従来の設定 -->
<a-marker smoothCount="10" smoothThreshold="5" ...>
```

- `smoothCount=10`: 10フレーム平均
- モバイルの低FPSと組み合わせると、レスポンスが遅延
- 検出開始が大幅に遅れる

---

## 🔧 実装した緊急対策

### 1. **高解像度の明示的指定**（最重要）

#### 変更内容
```html
<!-- 変更前 -->
<a-scene arjs="sourceType: webcam; ..." >

<!-- 変更後 -->
<a-scene arjs="sourceType: webcam; sourceWidth: 1280; sourceHeight: 960; 
               displayWidth: 1280; displayHeight: 960; ..." >
```

#### パラメータ説明

| パラメータ | 値 | 説明 |
|----------|---|------|
| **sourceWidth** | 1280 | カメラ入力解像度（幅） |
| **sourceHeight** | 960 | カメラ入力解像度（高さ） |
| **displayWidth** | 1280 | 表示解像度（幅） |
| **displayHeight** | 960 | 表示解像度（高さ） |

#### なぜ1280x960なのか？

- **4:3のアスペクト比**: モバイルカメラの標準比率
- **縦向き対応**: 960の高さで縦向き表示に最適
- **HD級の解像度**: 遠距離検出に必要
- **モバイルでも処理可能**: 最新機種なら30fps維持

#### 効果
- **検出距離が3-4倍に拡大**（予想）
- 遠距離でもマーカーの特徴点を明確に捉える
- PCと同等の検出性能を実現

### 2. **minConfidenceの大幅引き下げ**

#### 変更内容
```html
<!-- 変更前 -->
<a-marker minConfidence="0.6" ...>

<!-- 変更後 -->
<a-marker minConfidence="0.5" ...>
```

#### なぜ0.5なのか？

| 値 | 感度 | 検出距離 | 誤検出リスク |
|----|------|---------|------------|
| 0.7-0.8 | 低い | 10cm以内 | 低い |
| **0.5-0.6** | **中程度** | **20-40cm** | **中程度** |
| 0.3-0.4 | 高い | 40cm以上 | 高い |

#### 効果
- 低解像度でも検出可能に
- 遠距離・斜め角度での検出率向上
- **誤検出とのバランス**を考慮した最適値

### 3. **Smoothing設定の軽量化**

#### 変更内容
```html
<!-- 変更前 -->
<a-marker smoothCount="10" smoothTolerance="0.01" smoothThreshold="5" ...>

<!-- 変更後 -->
<a-marker smoothCount="5" smoothTolerance="0.02" smoothThreshold="2" ...>
```

#### パラメータ変更の理由

| パラメータ | 変更前 | 変更後 | 理由 |
|----------|-------|-------|------|
| **smoothCount** | 10 | 5 | レスポンス速度向上 |
| **smoothTolerance** | 0.01 | 0.02 | 小さな動きを許容 |
| **smoothThreshold** | 5 | 2 | 早期にスムージング開始 |

#### 効果
- 検出開始の遅延を半減
- モバイルの低FPSでも快適に
- ジッター低減は維持

### 4. **詳細デバッグログの追加**

#### カメラ情報の取得
```javascript
// カメラ解像度の確認
navigator.mediaDevices.getUserMedia({ video: true })
  .then((stream) => {
    const settings = track.getSettings();
    console.log('[Camera] 実際の解像度:', settings.width, 'x', settings.height);
    console.log('[Camera] フレームレート:', settings.frameRate);
  });
```

#### マーカー詳細情報
```javascript
console.log(`[Marker] 検出成功`);
console.log(`  角度: X=${angleX}° Y=${angleY}° Z=${angleZ}°`);
console.log(`  推定距離: ${distance}m (${(distance * 100).toFixed(0)}cm)`);
console.log(`  スケール: ${scale.x.toFixed(2)}`);
```

#### 効果
- 実際のカメラ解像度を確認可能
- 検出距離の測定が可能
- 問題の切り分けが容易に

## ⚠️ トレードオフと注意事項

### パフォーマンスの低下

#### FPS低下
- 予想: 25-35fps → 20-30fps
- 影響: アニメーションが若干カクつく可能性
- 対策: VRMアニメーションのフレーム数を削減

#### CPU/GPU負荷増加
- 高解像度処理により負荷増加
- 古い機種（3年以上前）では発熱の可能性
- 対策: デバイス世代の推奨を明記

#### 起動時間の増加
- カメラ初期化に1-2秒余分にかかる
- ユーザーに「初期化中」表示を強化

### 誤検出のリスク増加

#### minConfidence低下の影響
- `0.6` → `0.5`により、誤検出の可能性が若干増加
- 似たパターンを誤認識する可能性
- 対策: 背景がシンプルな場所での使用を推奨

## 🔄 問題が解決しない場合の代替策

### 代替策1: 段階的な解像度調整

デバイスの性能に応じて解像度を調整：

```javascript
// デバイス性能の推定
const isHighEnd = window.devicePixelRatio >= 2 && window.innerWidth >= 375;

const resolution = isHighEnd 
  ? { width: 1280, height: 960 }  // 高性能機種
  : { width: 960, height: 720 };   // 低性能機種

scene.setAttribute('arjs', `sourceWidth: ${resolution.width}; sourceHeight: ${resolution.height}; ...`);
```

### 代替策2: マーカーサイズの拡大

名刺上のペンギンロゴを5cm以上に拡大：
- 現在: 3-4cm
- 提案: 5-6cm
- 効果: 遠距離検出が容易に

### 代替策3: 複数マーカーの配置

名刺の表裏に異なるマーカーを配置：
- 表: メインマーカー（ペンギンロゴ）
- 裏: サブマーカー（Cor.Incロゴ）
- 効果: 検出率の相互補完
