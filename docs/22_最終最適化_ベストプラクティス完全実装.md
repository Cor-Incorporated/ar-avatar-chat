## 🚀 追加実装した4つの改善

### 1. **解像度フォールバック**（互換性向上）

#### 問題
- 古い機種では1280x960の高解像度が利用不可
- OverconstrainedErrorでカメラアクセス失敗の可能性
- ユーザーに状況が伝わらない

#### 実装内容

```javascript
// getUserMediaでideal/min制約を使用
navigator.mediaDevices.getUserMedia({ 
  video: { 
    width: { ideal: 1280, min: 640 }, 
    height: { ideal: 960, min: 480 } 
  } 
})
.then((stream) => {
  const settings = track.getSettings();
  console.log('[Camera] 実際の解像度:', settings.width, 'x', settings.height);
  
  // フォールバック警告
  if (settings.width < 1280 || settings.height < 960) {
    console.warn('[Camera] ⚠️ 高解像度が利用不可、フォールバック動作中');
    console.warn('[Camera] 検出距離が短くなる可能性があります');
    document.querySelector('#status').textContent = '⚠️ カメラ解像度制限あり';
  }
});
```

#### 効果
- ✅ 古い機種でもエラーなく起動
- ✅ 実際の解像度をユーザーに通知
- ✅ 期待値の調整が可能

#### 制約の動作

| 設定          | 意味                   |
|---------------|----------------------|
| `ideal: 1280` | 理想値（可能なら1280px）   |
| `min: 640`    | 最小値（640px未満は拒否） |
| `max: 1920`   | 最大値（不要なら省略可）   |

### 3. **minConfidence動的調整**（適応的検出）

#### 問題
- 固定の`minConfidence=0.5`では環境変化に対応不可
- 照明条件や距離で検出率が大きく変動
- ユーザーが手動調整できない

#### 実装内容

##### 連続Lost時の自動調整
```javascript
marker.addEventListener('markerLost', () => {
  lostCount++;
  
  // 3回連続Lost → 感度向上
  if (lostCount === 3) {
    marker.setAttribute('minConfidence', 0.45);
    console.log('[Marker] 感度向上: minConfidence 0.5 → 0.45');
  }
  
  // 7回連続Lost → さらに感度向上
  if (lostCount === 7) {
    marker.setAttribute('minConfidence', 0.4);
    console.log('[Marker] 感度さらに向上: minConfidence 0.45 → 0.4');
  }
});
```

##### 検出成功時のリセット
```javascript
marker.addEventListener('markerFound', () => {
  // 検出成功したら初期値に戻す
  if (currentConfidence < 0.5) {
    marker.setAttribute('minConfidence', 0.5);
    console.log('[Marker] 感度リセット: minConfidence → 0.5');
  }
});
```

#### 動作フロー

| Lost回数 | minConfidence | 検出感度 | 誤検出リスク |
|---------|---------------|---------|----------|
| 0-2回    | 0.5           | 中程度   | 中程度    |
| 3-6回    | 0.45          | やや高い    | やや高い     |
| 7回以上  | 0.4           | 高い      | 高い       |
| 検出成功 | 0.5（リセット）     | 中程度   | 中程度    |

#### 効果
- ✅ 環境変化に自動適応
- ✅ ユーザーの手間を削減
- ✅ 検出率の向上（平均10-15%改善予想）
